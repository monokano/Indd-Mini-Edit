メニュー

入力欄を右クリックするか、入力バーの左端の「⋯」ボタンをクリックすると、メニューが出ます。「⋯」ボタンのメニューには、カット、コピー、ペーストはありません。それ以外の項目は同じです。

文字サイズ、フォント、入力キー、「改行を入力しない」は、選んだ時点で保存され、次に起動したときもそのまま使われます。

カット／コピー／ペースト
入力欄の文字をカット、コピー、ペーストします（右クリックのメニューのみ）。
Indd Mini-Editについて
バージョンなどの情報を表示します。
ヘルプ
このヘルプを表示します。
文字サイズ
入力欄の文字の大きさを14、16、18、20、22、24から選びます。初期状態は16です。InDesignへ送る文字の書式には影響しません。
フォント
入力欄のフォントを、ヒラギノ角ゴシック W3、ヒラギノ明朝 ProN W3、游ゴシック体 ミディアム、游明朝体 ミディアムから選びます。初期状態はヒラギノ角ゴシック W3です。Macに入っていないフォントは選べません。InDesignへ送る文字の書式には影響しません。
入力キー
InDesignへ送るキーを、⌥ + return ⌘ + return return から選びます。初期状態は ⌥ + return です。return にすると、入力欄で改行できなくなります。
改行を入力しない
「入力キー」の中にあります。オンにすると、入力欄で return などを押しても改行されません。初期状態はオンです。改行を含む文字をペーストしたときや、自動保存を読み込んだときの改行は、そのまま入ります。入力キーが return のときは常にオンで、変えられません。
位置
「位置を調整」は、画面からはみ出した入力バーを画面の中に収めます。「リセット」は、入力バーを初期状態の高さで、画面の下端に横いっぱいの位置に戻します。
自動保存を読み込む
前回終了したときに自動保存された文字を、入力欄に読み込みます。入力欄にあった文字は置き換わりますが、⌘Z で読み込む前に戻せます。保存された文字が無いときは選べません。詳しくは入力と送信をご覧ください。
英数字を全角に／英数字を半角に
選択した範囲の英数字（0〜9、a〜z、A〜Z）を、全角または半角に変換します。記号、スペース、カタカナは変わりません。文字を選択しているときだけ選べます。⌘Z で変換前に戻せます。
