権限とトラブルシューティング

オートメーション（Apple イベント）の許可

Indd Mini-Edit が InDesign へ文字を入力するには、オートメーション（Apple イベント）の許可が必要です。初めて送信したときに許可を求めるダイアログが表示されるので、「許可」を選んでください。

許可しなかった場合は、送信したときに許可を促すメッセージが表示されます。「システム設定」の「プライバシーとセキュリティ」›「オートメーション」を開き、Indd Mini-Edit の下にある InDesign の項目をオンにしてください。

メモ Indd Mini-Edit はアクセシビリティの権限を必要としません。

メッセージの意味

InDesign へ送れなかったときは、入力バーの上に赤い文字でメッセージが表示されます。入力した文字は残っているので、原因を取り除いてからもう一度送ってください。

起動しているInDesignがありません
InDesign が起動していません。InDesign を起動して、テキストを選択してから送ってください。
InDesignを最前面にしてください
送り先の InDesign を決められませんでした（複数のバージョンを起動していて、どの InDesign のウインドウも画面に見えていない場合など）。送りたい InDesign をクリックして最前面にしてから、入力バーをクリックして送ってください。
InDesignドキュメントがありません
InDesign でドキュメントが開いていません。ドキュメントを開いて、テキストを選択してから送ってください。
ドキュメントでテキストが選択されていません
InDesign でテキストが選択されていないか、カーソルがテキストの中にありません（テキストフレームなどのオブジェクトを選択している場合を含む）。入力したい位置のテキストを選択するか、テキストの中にカーソルを置いてから送ってください。
ドキュメントウインドウがDockにしまわれています
送り先の InDesign で、作業中のドキュメントウインドウが Dock にしまわれています。見えないドキュメントに入力しないよう、送らずに止めました。Dock からウインドウを元に戻してから送ってください。ウインドウが別の操作スペースにある場合も、このメッセージが表示されます。
「システム設定」>「プライバシーとセキュリティ」>「オートメーション」で、Indd Mini-EditにInDesignの操作を許可してください
オートメーションが許可されていません。上の「オートメーション（Apple イベント）の許可」をご覧ください。
InDesignにテキストを送れませんでした
InDesign が応答しなかったなどの理由で送れませんでした。InDesign が処理中でないか（ダイアログが開いていないかなど）を確認して、もう一度送ってください。

うまく動かないとき

入力キーを押しても送られない
設定した入力キーの組み合わせのとおりに押しているか確認してください（ほかの修飾キーを一緒に押していると送られません）。日本語の変換中は送られないので、変換を確定してから押してください。いまの入力キーはメニューの「入力キー」で確認できます。
入力欄で改行できない
入力キーが return になっていると、改行できません。改行したいときは、メニューの「入力キー」で ⌥ + return か ⌘ + return を選んでください。
入力バーが見当たらない
入力バーが画面の外に出ていることがあります。Indd Mini-Edit を起動し直すと、画面の中に収まるように調整されます。
間違えて閉じてしまった
もう一度起動して、メニューの「自動保存を読み込む」を選ぶと、閉じる前の文字を戻せます。
