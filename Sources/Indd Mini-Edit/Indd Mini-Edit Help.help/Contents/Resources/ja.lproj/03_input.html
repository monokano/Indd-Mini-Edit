入力と送信

入力する

起動すると、入力バーはすぐに入力できる状態になります。InDesignが最前面のまま、日本語入力もそのまま使えます。InDesignをクリックしたあとでも、入力バーをクリックすれば続けて入力できます。

カット（⌘X）、コピー（⌘C）、ペースト（⌘V）、すべてを選択（⌘A）、取り消す（⌘Z）、やり直す（⇧⌘Z）が使えます。

macOSの機能（引用符やダッシュの自動置換、スペルの自動修正）はオフにしています。入力したとおりの文字がInDesignへ送られます。

改行して複数行にする

初期状態では、入力欄で改行できません（メニューの「入力キー」›「改行を入力しない」がオンのため）。改行したいときは、これをオフにします。オフにすると、return で改行できます（入力キーを return にしているときを除く）。複数行を入力するときは、入力バーの上の縁をドラッグして高さを広げると見やすくなります。改行は、InDesignでは段落の区切りになります。

スペースや改行の記号

入力欄では、目に見えない文字がピンクの記号で表示されます。主な記号は次のとおりです。

  • スペース：.
  • 全角スペース：□
  • タブ：⇥
  • 改行：¶
  • ノーブレークスペース：⌄
  • ゼロ幅スペースなど：¦

記号は入力欄での表示だけで、InDesignへは元の文字のまま送られます。

InDesignへ送る

入力を終えたら、⌥ + return（初期状態）を押します。InDesignの選択範囲が入力した文字に置き換わり、Indd Mini-Editは終了します。

  • 置き換えたあと、InDesignのカーソルは入力した文字の後ろに置かれます。
  • 選択範囲の先頭の文字の書式が、入力した文字に適用されます。
  • InDesignで ⌘Z を1回押すと、入力する前に戻せます。
  • 入力欄が空のまま送ると、何もせずに終了します。

入力キーは、設定した組み合わせのとおりに押したときだけ働きます。たとえば ⌥ + return のときに ⌥⇧ + return を押しても送られません。日本語の変換中に押した場合も送られません（変換の確定に使われます）。入力キーはメニューで変えられます。

送り先のInDesign

入力した文字は、次の順で決まるInDesignに送られます。

  1. 最前面のInDesign
  2. 最後に最前面になったInDesign（Indd Mini-Editを起動してからほかのInDesignに切り替えていなければ、起動したときに最前面だったInDesign）
  3. 画面上でいちばん手前にウインドウがあるInDesign
  4. 起動しているInDesignが1つだけなら、そのInDesign

ほかのアプリを使っていてInDesignが最前面でなくなっていても、最後に最前面だったInDesignへ送られます。そのときは、入力したあとにInDesignが最前面になります。複数のバージョンのInDesignを同時に起動していて、どのInDesignのウインドウも画面に見えていないなど、送り先が決まらないときは、「InDesignを最前面にしてください」と表示されます。

送れなかったとき

InDesignへ送れなかったときは、入力バーの上に赤い文字でメッセージが表示され、Indd Mini-Editは終了しません。入力した文字はそのまま残るので、原因を取り除いてからもう一度送ってください。メッセージの意味は権限とトラブルシューティングをご覧ください。

閉じる

送らずに閉じるときは、次のどれかを行います。どれもIndd Mini-Editを終了します。

  • 閉じるアイコンをクリックする
  • esc を押す（日本語の変換中は、変換の取り消しになります）
  • ⌘W または ⌘Q を押す

自動保存

Indd Mini-Editを終了するとき、入力欄の文字は自動で保存されます（送ったとき、閉じたときのどちらも）。間違えて閉じてしまったときや、前に送った文字をもう一度使いたいときは、次に起動してからメニューの「自動保存を読み込む」を選ぶと、入力欄に戻せます。

  • 保存されるのは、最後に終了したときの内容だけです。
  • 入力欄が空のまま終了すると、保存された文字は消え、「自動保存を読み込む」は選べなくなります。

入力バーの位置と大きさ

入力バーは、初めて起動したときは画面の下端に横いっぱいで表示されます。

  • 移動：左端（閉じるアイコンのあたり）をドラッグします。
  • 大きさ：上下左右の縁をドラッグします。

位置と大きさは記憶され、次に起動したときも同じ場所に表示されます。画面の構成が変わって画面からはみ出したときは、画面の中に収まるように自動で調整されます。元の位置に戻すときは、メニューの「位置」›「リセット」を選びます。
