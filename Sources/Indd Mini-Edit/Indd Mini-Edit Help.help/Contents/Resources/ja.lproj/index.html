Indd Mini-Edit ヘルプ

Indd Mini-Edit は、Adobe InDesign での日本語入力を補助するアプリです。画面の下端に出る入力バーで文字を入力し、キー操作ひとつで InDesign の選択範囲へ入力します。

  • Indd Mini-Edit について アプリの概要・使い方の流れ
  • 準備 Dock から起動する・キーボードショートカットで起動する
  • 入力と送信 入力バーの操作・InDesign へ送る・閉じる・自動保存
  • メニュー 文字サイズ・フォント・入力キー・位置・英数字の全角／半角
  • 権限とトラブルシューティング オートメーションの許可・メッセージの意味・うまく動かないとき
