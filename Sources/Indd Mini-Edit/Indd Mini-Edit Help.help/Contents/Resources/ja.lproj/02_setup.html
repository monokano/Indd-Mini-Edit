準備

Indd Mini-Edit は、Dock に置いてクリックで起動するのがいちばん手軽な使い方です。さらに、InDesign のスクリプトのキーボードショートカットを割り当てておくと、キー操作だけで起動できて、より効率よく使えます。

Dock から起動する

  1. Indd Mini-Edit を Dock にドラッグして置きます。
  2. InDesign で、置き換えたいテキストを選択します（テキストの中にカーソルを置くだけでもかまいません）。
  3. Dock の Indd Mini-Edit をクリックします。画面の下端に入力バーが出ます。

Dock から起動しても、InDesign は最前面のままで、入力バーはすぐに入力できる状態になります。文字は、起動したときに使っていた InDesign に入力されます。

より効率的な方法：キーボードショートカットで起動する

Indd Mini-Edit を InDesign のスクリプトパネルに入れると、InDesign のスクリプトとしてキーボードショートカットを割り当てられます。

InDesign のスクリプトパネルに入れる

  1. InDesign で「ウィンドウ」メニュー ›「ユーティリティ」›「スクリプト」を選び、スクリプトパネルを開きます。
  2. スクリプトパネルの「ユーザー」フォルダを右クリックし、「Finder で表示」を選びます。
  3. Finder に表示された「Scripts Panel」フォルダに、Indd Mini-Edit を入れます。アプリ本体のかわりに、エイリアスを入れてもかまいません。
  4. スクリプトパネルの「ユーザー」に「Indd Mini-Edit」が表示されます。ダブルクリックすると起動します。

キーボードショートカットを割り当てる

  1. InDesign で「編集」メニュー ›「キーボードショートカット…」を選びます。
  2. 「機能エリア」で「スクリプト」を選び、一覧から「Indd Mini-Edit」を選びます。
  3. 「新規ショートカット」の欄をクリックして ⌥ + return を押し、「内容」を「テキスト」に設定して、「割り当て」をクリックします。
  4. 「OK」をクリックします（初期設定のセットは変更できないため、新しいセットとして保存するよう求められたときは、名前を付けて保存します）。

「内容」を「テキスト」にすると、このショートカットは InDesign でテキストを編集しているときだけ働きます。ほかの場面での ⌥ + return の操作を妨げません。

これで、InDesign でテキストを選択して（またはテキストの中にカーソルを置いて）⌥ + return を押すと、入力バーが出ます。入力を終えたら、もう一度 ⌥ + return を押すと InDesign へ入力されます。起動と送信を同じキーにしておくと、手の動きが少なくて済みます。

メモ 送信に使うキー（入力キー）は、⌥ + return、⌘ + return、return から選べます。詳しくはメニューをご覧ください。

オートメーションの許可

Indd Mini-Edit が InDesign へ文字を入力するには、オートメーション（Apple イベント）の許可が必要です。初めて送信したときに許可を求めるダイアログが表示されるので、「許可」を選んでください。詳しくは権限とトラブルシューティングをご覧ください。
