About Indd Mini-Edit

What the app does

Indd Mini-Edit is an app that makes Japanese text entry in Adobe InDesign easier. Instead of typing directly into your InDesign text, you type and refine it in a slim input bar at the bottom of the screen. When it’s ready, press a single key to place it into the selection in InDesign.

InDesign stays in front while you use the input bar, so you can keep looking at your InDesign layout as you type.

Basic workflow

  1. In InDesign, select the text you want to replace (or just place the cursor in the text).
  2. Launch Indd Mini-Edit (click its icon in the Dock, or use a keyboard shortcut). The input bar appears at the bottom of the screen.
  3. Type in the input bar, then press ⌥ + return (the default).
  4. The selection in InDesign is replaced with what you typed, and Indd Mini-Edit quits.

Indd Mini-Edit launches and quits once for each entry. To enter more text, launch it again.

Tip You can keep Indd Mini-Edit in the Dock and click it to launch. For even faster use, add it as an InDesign script and assign a keyboard shortcut, so a single keystroke launches it. See Getting Started for details.

The input bar

At the left end of the input bar are a close icon and a “⋯” button.

Close icon
Click to close the input bar and quit Indd Mini-Edit. It appears blue (white in Dark Mode) when the input bar is ready for typing, and gray when you’ve clicked away to InDesign or another app.
“⋯” button
Click to open a menu for changing the text size, font, send key, and more. See Menu for details.

Invisible characters you type in the input field, such as spaces and full-width spaces, are shown as pink symbols. See Typing and Sending for details.

System requirements

  • macOS 13.5 or later
  • Adobe InDesign (works even when several versions are running at the same time)
