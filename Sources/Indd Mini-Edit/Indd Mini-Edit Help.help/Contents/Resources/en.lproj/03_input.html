Typing and Sending

Typing

When the app launches, the input bar is ready for typing right away. InDesign stays in front, and you can use your Japanese input method as usual. If you click InDesign, just click the input bar to continue typing.

You can use Cut (⌘X), Copy (⌘C), Paste (⌘V), Select All (⌘A), Undo (⌘Z), and Redo (⇧⌘Z).

macOS features such as smart quotes, smart dashes, and automatic spelling correction are turned off. The text is sent to InDesign exactly as you typed it.

Typing multiple lines

Press return to start a new line (unless the send key is set to return). When typing multiple lines, drag the top edge of the input bar to make it taller and easier to read. In InDesign, each line break becomes a paragraph break.

Symbols for spaces and line breaks

In the input field, invisible characters are shown as pink symbols. The main symbols are:

  • Space: .
  • Full-width space: □
  • Tab: ⇥
  • Line break: ¶
  • No-break space: ⌄
  • Zero-width space and similar: ¦

The symbols appear only in the input field. The original characters are sent to InDesign.

Sending to InDesign

When you’ve finished typing, press ⌥ + return (the default). The selection in InDesign is replaced with what you typed, and Indd Mini-Edit quits.

  • After the replacement, the InDesign cursor is placed after the text you entered.
  • The formatting of the first character in the selection is applied to the text you entered.
  • Press ⌘Z once in InDesign to go back to how it was before.
  • If the input field is empty, the app quits without doing anything.

The send key works only when you press exactly the key combination you set. For example, if it’s ⌥ + return, pressing ⌥⇧ + return doesn’t send. It also doesn’t send while Japanese text is being converted (the key confirms the conversion instead). You can change the send key in the menu.

Which InDesign receives the text

The text you entered goes to the InDesign chosen in this order:

  1. The InDesign in front
  2. The InDesign that was most recently in front (if you haven’t switched to another InDesign since launching Indd Mini-Edit, the one that was in front at launch)
  3. The InDesign whose window is frontmost on screen
  4. If only one InDesign is running, that one

Even if you switched to another app and InDesign is no longer in front, the text goes to the InDesign that was most recently in front, and that InDesign then comes to the front. If several versions of InDesign are running and the destination can’t be determined (for example, no InDesign window is visible on screen), “Bring InDesign to the front.” appears.

If the text couldn’t be sent

If the text couldn’t be sent to InDesign, a message appears in red above the input bar, and Indd Mini-Edit doesn’t quit. Your text stays in place, so fix the cause and send it again. For what each message means, see Permissions and Troubleshooting.

Closing

To close without sending, do one of the following. Each one quits Indd Mini-Edit.

  • Click the close icon.
  • Press esc. (While Japanese text is being converted, this cancels the conversion.)
  • Press ⌘W or ⌘Q.

Auto-save

When Indd Mini-Edit quits, the text in the input field is saved automatically (whether you sent it or closed the app). If you closed by mistake, or want to reuse text you sent earlier, launch the app again and choose Load Auto-Saved Text from the menu to bring it back into the input field.

  • Only the contents from the last time the app quit are saved.
  • If the app quits with the input field empty, the saved text is cleared and Load Auto-Saved Text can’t be chosen.

Position and size of the input bar

The first time you launch the app, the input bar appears across the full width of the bottom of the screen.

  • To move it: drag its left end (around the close icon).
  • To resize it: drag any edge.

The position and size are remembered, and the input bar appears in the same place the next time. If your display setup changes and the bar ends up off screen, it’s adjusted automatically to fit on screen. To return it to its original position, choose Position › Reset Position from the menu.
