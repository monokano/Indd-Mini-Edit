Menu

Right-click the input field, or click the “⋯” button at the left end of the input bar, to open the menu. The “⋯” button’s menu doesn’t include Cut, Copy, and Paste; otherwise the items are the same.

The text size, font, send key, and Disallow Line Breaks setting are saved as soon as you choose them, and are used again the next time you launch the app.

Cut / Copy / Paste
Cut, copy, or paste text in the input field (right-click menu only).
About Indd Mini-Edit
Shows the version and other information.
Help
Shows this help.
Text Size
Choose the size of the text in the input field from 14, 16, 18, 20, 22, and 24. The default is 16. This doesn’t affect the formatting of the text sent to InDesign.
Font
Choose the font for the input field from Hiragino Sans W3, Hiragino Mincho ProN W3, Yu Gothic Medium, and Yu Mincho Medium. The default is Hiragino Sans W3. Fonts that aren’t installed on your Mac can’t be chosen. This doesn’t affect the formatting of the text sent to InDesign.
Send Key
Choose the key that sends text to InDesign from ⌥ + return, ⌘ + return, and return. The default is ⌥ + return. If you choose return, you can’t start a new line in the input field.
Disallow Line Breaks
Found in the Send Key submenu. When it’s on, pressing return and similar keys doesn’t start a new line in the input field. It’s on by default. Line breaks in pasted text or in loaded auto-saved text are kept. When the send key is return, it’s always on and can’t be changed.
Position
Adjust Position moves an input bar that’s off screen back onto the screen. Reset Position returns the input bar to its default height, across the full width of the bottom of the screen.
Load Auto-Saved Text
Loads the text that was auto-saved when the app last quit into the input field. It replaces any text already in the input field, but you can press ⌘Z to go back. This can’t be chosen when there’s no saved text. See Typing and Sending for details.
Convert Alphanumerics to Full-Width / Convert Alphanumerics to Half-Width
Converts the letters and digits (0–9, a–z, A–Z) in the selection to full-width or half-width. Symbols, spaces, and katakana aren’t changed. Available only when text is selected. Press ⌘Z to undo the conversion.
