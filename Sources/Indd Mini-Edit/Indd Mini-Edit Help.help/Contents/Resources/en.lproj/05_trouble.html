Permissions and Troubleshooting

Allowing automation (Apple events)

To place text into InDesign, Indd Mini-Edit needs permission for automation (Apple events). The first time you send text, a dialog asks for permission; choose Allow.

If you didn’t allow it, a message asking for permission appears when you send. Open System Settings › Privacy & Security › Automation, and turn on InDesign under Indd Mini-Edit.

Note Indd Mini-Edit doesn’t need Accessibility permission.

What the messages mean

If the text couldn’t be sent to InDesign, a message appears in red above the input bar. Your text is still there, so fix the cause and send it again.

No InDesign is running.
InDesign isn’t running. Open InDesign, select some text, then send.
Bring InDesign to the front.
The destination InDesign couldn’t be determined (for example, several versions are running and no InDesign window is visible on screen). Click the InDesign you want to send to so it comes to the front, then click the input bar and send.
There is no InDesign document.
No document is open in InDesign. Open a document, select some text, then send.
No text is selected in the document.
No text is selected in InDesign, or the cursor isn’t in the text (including when an object such as a text frame is selected). Select the text where you want to enter, or place the cursor in the text, then send.
The document window is minimized in the Dock.
The active document window of the destination InDesign is minimized in the Dock. The text wasn’t sent, so it doesn’t go into a document you can’t see. Restore the window from the Dock, then send. This message also appears if the window is in another desktop space.
Allow Indd Mini-Edit to control InDesign in System Settings > Privacy & Security > Automation.
Automation isn’t allowed. See “Allowing automation (Apple events)” above.
Couldn’t send the text to InDesign.
The text couldn’t be sent, for example because InDesign didn’t respond. Check that InDesign isn’t busy (for example, that no dialog is open), then send again.

When something doesn’t work

Pressing the send key doesn’t send
Make sure you’re pressing exactly the send key combination you set (it doesn’t send if other modifier keys are held down). It doesn’t send while Japanese text is being converted, so confirm the conversion first. You can check the current send key under Send Key in the menu.
Can’t start a new line in the input field
When the send key is return, you can’t start a new line. To use line breaks, choose ⌥ + return or ⌘ + return under Send Key in the menu.
Can’t find the input bar
The input bar may be off screen. Relaunch Indd Mini-Edit, and it’s adjusted to fit on screen.
Closed by mistake
Launch the app again and choose Load Auto-Saved Text from the menu to bring back the text from before you closed.
