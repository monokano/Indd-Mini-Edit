Getting Started

The easiest way to use Indd Mini-Edit is to keep it in the Dock and click it to launch. For even more efficient use, assign it a keyboard shortcut as an InDesign script, so you can launch it from the keyboard alone.

Launch from the Dock

  1. Drag Indd Mini-Edit to the Dock.
  2. In InDesign, select the text you want to replace (or just place the cursor in the text).
  3. Click Indd Mini-Edit in the Dock. The input bar appears at the bottom of the screen.

Even when launched from the Dock, InDesign stays in front and the input bar is ready for typing right away. The text goes to the InDesign you were using when you launched the app.

A more efficient way: launch with a keyboard shortcut

When you put Indd Mini-Edit in the InDesign Scripts panel, you can assign it a keyboard shortcut as an InDesign script.

Add it to the InDesign Scripts panel

  1. In InDesign, choose Window › Utilities › Scripts to open the Scripts panel.
  2. In the Scripts panel, right-click the User folder and choose Reveal in Finder.
  3. Put Indd Mini-Edit into the Scripts Panel folder shown in the Finder. You can also put an alias of the app there instead of the app itself.
  4. Indd Mini-Edit now appears under User in the Scripts panel. Double-click it to launch.

Assign a keyboard shortcut

  1. In InDesign, choose Edit › Keyboard Shortcuts.
  2. For Product Area, choose Scripts, then choose Indd Mini-Edit in the list.
  3. Click the New Shortcut field and press ⌥ + return, set Context to Text, then click Assign.
  4. Click OK. (The default set can’t be changed, so if you’re asked to save a new set, give it a name and save it.)

With Context set to Text, the shortcut works only while you’re editing text in InDesign, so it doesn’t interfere with ⌥ + return anywhere else.

Now, when you select text in InDesign (or place the cursor in the text) and press ⌥ + return, the input bar appears. When you’ve finished typing, press ⌥ + return again to send the text to InDesign. Using the same key to launch and send keeps your hands still.

Note The key used to send (the send key) can be ⌥ + return, ⌘ + return, or return. See Menu for details.

Allowing automation

To place text into InDesign, Indd Mini-Edit needs permission for automation (Apple events). The first time you send text, a dialog asks for permission; choose Allow. See Permissions and Troubleshooting for details.
