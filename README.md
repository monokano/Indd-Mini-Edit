# Indd Mini-Edit

macOS用デスクトップアプリ

## 用途

Indd Mini-Edit は、Adobe InDesign での日本語入力を補助するアプリです。InDesign の本文に直接打ち込む代わりに、画面の下端に出る細長い入力バーで文字を入力して推敲し、できあがったらキー操作ひとつで InDesign の選択範囲へ入力します。入力バーは InDesign を最前面にしたまま使えるので、InDesign の画面を見ながら、そのまま日本語を入力できます。

## 機能

- **入力バー**：画面の下端に細長い入力バーを表示します。InDesign を最前面にしたまま、日本語入力やショートカットが使えます。
- **選択範囲へ入力**：入力キー（初期状態は ⌥ + return）を押すと、入力した文字で InDesign の選択範囲を置き換え、Indd Mini-Edit は終了します。入力キーは ⌥ + return、⌘ + return、return から選べます。
- **不可視文字の表示**：入力した欧文スペース、全角スペースなどの不可視文字を、ピンクの記号で表示します。
- **英数字の全角／半角変換**：選択した英数字を、右クリックメニューで全角または半角に変換します。
- **自動保存**：入力中の文字を自動保存し、あとから読み込めます。
- **起動のしかた**：Dock のアイコンをクリックして起動できます。さらに InDesign のスクリプトパネルに入れてキーボードショートカットを割り当てると、キー操作ひとつで起動できて効率的です。

詳細は、入力バーの「⋯」ボタンから「ヘルプ」を選択してください。


## 動作環境

macOS 13.5 Ventura 以降（Universal Binary）

Adobe InDesign（複数のバージョンを同時に起動していても使えます）
